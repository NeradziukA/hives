# Расчёты — Скорость движения патруля

## Шаг за тик

Каждые `NPC_TICK_INTERVAL_MS` (10 с) сервер вычисляет, на сколько метров NPC продвигается за прошедший интервал:

```
stepM = speed × elapsed_s
```

| Параметр   | Источник                                  |
| ---------- | ----------------------------------------- |
| `speed`    | Поле `npc_patrols.speed`, единицы — м/с   |
| `elapsed_s`| Фактическое время с прошлого тика, с      |
| `stepM`    | Расстояние за тик, м                      |

Пример: патруль со скоростью `1.4 м/с` проходит `1.4 × 10 = 14 м` за тик.

---

## Геодезические вычисления

Расстояние между двумя точками маршрута вычисляется по формуле Хаверсинуса:

```
a = sin²(Δφ/2) + cos(φ₁) × cos(φ₂) × sin²(Δλ/2)
d = 2 × R × atan2(√a, √(1−a))
```

| Параметр | Описание                          |
| -------- | --------------------------------- |
| `φ`      | Широта в радианах                 |
| `λ`      | Долгота в радианах                |
| `R`      | Радиус Земли = 6 371 000 м        |
| `d`      | Расстояние между точками, м       |

Новая позиция при движении на `distanceM` метров в направлении следующего вейпоинта:

```
bearing = atan2(sin(Δλ)·cos(φ₂), cos(φ₁)·sin(φ₂) − sin(φ₁)·cos(φ₂)·cos(Δλ))
δ       = distanceM / R
φ₃      = asin(sin(φ₁)·cos(δ) + cos(φ₁)·sin(δ)·cos(bearing))
λ₃      = λ₁ + atan2(sin(bearing)·sin(δ)·cos(φ₁), cos(δ) − sin(φ₁)·sin(φ₃))
```

---

## Обход вейпоинтов

Вейпоинты обходятся в порядке возрастания поля `order`. Если `stepM` превышает расстояние до текущего вейпоинта, патруль «доходит» до него, вычитает пройденное расстояние из остатка и переходит к следующему. Процесс повторяется до исчерпания шага:

```
remaining = stepM
while remaining > 0:
    dist = haversine(current, target_waypoint)
    if dist ≤ remaining:
        remaining -= dist
        current   = target_waypoint
        advance waypoint index (wraps to 0 after last)
    else:
        current   = moveToward(current, target_waypoint, remaining)
        remaining = 0
```

После последнего вейпоинта индекс оборачивается на `0` — маршрут зацикливается.

---

## Тик-интервал и точность

| Параметр              | Значение  |
| --------------------- | --------- |
| `NPC_TICK_INTERVAL_MS`| 10 000 мс |
| Шаг при 1.0 м/с       | 10 м/тик  |
| Шаг при 1.4 м/с       | 14 м/тик  |
| Шаг при 2.0 м/с       | 20 м/тик  |

Используется фактическое elapsed-время (`Date.now() − lastTick`), а не константа — движение остаётся точным даже при дрейфе таймера.

---

## Хранение и трансляция

После каждого тика:
1. Новая позиция записывается в `players.lastLat / lastLng` — при рестарте сервера патруль возобновляется с ближайшего к сохранённой точке вейпоинта.
2. Всем подключённым клиентам рассылается сообщение `UNIT_MOVED { coords: { lat, lon } }`.
